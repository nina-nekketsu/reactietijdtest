# Mijn reactietijd

Statische Nederlandse leeractiviteit voor 2 havo, H4 Beweging.

- Drie of vier leerlingen per groep.
- Per leerling één oefenpoging en drie geldige metingen.
- Te vroeg klikken telt niet mee.
- Gemiddelde in milliseconden en seconden.
- Geen accounts of namen; resultaten bestaan alleen in het huidige tabblad.
- Geen backend, analytics, externe scripts of verzending van resultaten.
- Apparaat en browser beïnvloeden de meting: geen diagnostisch instrument of wedstrijd.

GitHub Pages levert de pagina; de hostingprovider kan gebruikelijke webservergegevens verwerken. De app zelf verstuurt geen resultaten.

`index.html` is byte-identiek aan de vooraf in de browser geteste offlineversie. Geen bouwstap of externe afhankelijkheden.

Voor lokaal gebruik: open `index.html` in een normale browser.
